# EXERCISE 01 · SQL FOUNDATIONS

This excercise is a beginner-friendly SQL practice that is  built around a single sample dataset called an employees table with 5 records across columns like department, salary, hire_date, and city.
It presents 10 questions that ask you to retrieve, sort, and filter data from that table ,we are writing the SQL query , then by working out what the query would return, without running any code.
The exercise is a handwritten, pen-and-paper worksheet (PDF), covering:

SELECT (all columns and specific columns)
DISTINCT
ORDER BY (ascending and descending)
LIMIT
WHERE, combined with AND, OR, NOT, and IN
